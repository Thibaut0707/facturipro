# Facturi Pro

Application web moderne de gestion et de facturation destinée aux entreprises et travailleurs autonomes.

## Aperçu

Facturi Pro permet de simplifier la gestion des opérations de facturation grâce à une interface moderne, intuitive et responsive.

L’application offre aux utilisateurs la possibilité de gérer leurs clients, créer des factures et suivre les paiements de manière efficace.

## Fonctionnalités

- Création et gestion de factures
- Gestion des clients
- Tableau de bord interactif
- Suivi des paiements
- Interface moderne et responsive
- Navigation fluide et optimisée

## Technologies utilisées

- Next.js
- React
- TypeScript
- JavaScript
- CSS
- SQL
